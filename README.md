# GovFlow AI — aperçu portfolio

Vitrine publique d’une plateforme de rédaction, de validation et de suivi de documents administratifs.

> Ce dépôt est une présentation statique indépendante. Il ne contient ni le code du
> produit, ni ses règles métier, ni ses données, ni ses documents internes.

## Fonctionnalités présentées

- tableau de bord documentaire ;
- rédaction assistée par IA ;
- circuits de validation configurables ;
- modèles de documents ;
- base documentaire et recherche ;
- notifications, historique et traçabilité.

Toutes les références, personnes, services, dates et statistiques visibles dans la vitrine sont fictifs.

## Technologies du produit privé

React, TypeScript, Node.js, Express, MongoDB, automatisation n8n et intégration d’IA générative.

## Périmètre public

Ce dépôt ne contient :

- aucun document, PDF ou contenu administratif réel ;
- aucun nom, courriel, compte ou donnée personnelle réelle ;
- aucune information identifiant une administration ou un établissement ;
- aucun secret, fichier d’environnement, jeton ou identifiant d’accès ;
- aucun prompt interne, workflow détaillé, règle métier ou code applicatif privé ;
- aucune sauvegarde, base de données ou journal technique.
